BUILT FOR CONSISTENCY

One request. One settlement.

  1. 1
    Recognize the request

    Redis checks the key and request fingerprint.

  2. 2
    Lock the accounts

    PostgreSQL locks both rows in account ID order.

  3. 3
    Commit together

    Balances, ledger, and final status commit atomically.

  4. 4
    Recover with the same key

    The database preserves the result after Redis expiry.
